### Начало работы

npm i

### Команды npm run

db:generate - создает папку с правилами миграции

db:migrate - создает базу данных на основе папки миграции

db:seed - наполняет базу данными

db:studio - запускает запуск программы для работы с бд

### Файлы

drizzle.config.ts - конфигурация drizzle

index.ts - правила создания бд

schema.ts - создание таблиц и связей между ними

migrate.ts - правила миграции бд

seed.ts - данные для наполнения бд
